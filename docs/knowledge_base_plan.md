# GovAssist Knowledge Base Plan

## Part B — Source Documents

This section lists the sources selected for the GovAssist knowledge base.

### Source Priority

Sources are prioritised in the following order:

 1.⁠ ⁠Australian Government departments and agencies
 2.⁠ ⁠Statutory authorities
 3.⁠ ⁠State government sources
 4.⁠ ⁠Other authoritative organisations where government information is not available

### URL Status

•⁠  ⁠*Confirmed* — URL has been checked and is accessible.
•⁠  ⁠*To verify* — source has been identified, but the exact URL still needs to be checked.

# Metadata Requirements

Each document added to the knowledge base should have the following metadata:

| Field | Description |
|---|---|
| ⁠ document_id ⁠ | Unique document identifier |
| ⁠ title ⁠ | Document title |
| ⁠ organisation ⁠ | Publishing organisation |
| ⁠ category ⁠ | Main topic |
| ⁠ jurisdiction ⁠ | Federal, VIC, NSW, etc. |
| ⁠ url ⁠ | Original source URL |
| ⁠ source_type ⁠ | Web, PDF, dataset, etc. |
| ⁠ date_collected ⁠ | Date the document was collected |
| ⁠ last_updated ⁠ | Source update date, if available |
| ⁠ valid_from ⁠ | Start of validity, if known |
| ⁠ valid_until ⁠ | End of validity, if known |
| ⁠ financial_year ⁠ | Financial year for financial thresholds |
| ⁠ status ⁠ | Confirmed or To verify |

---

# Data Collection Rules

 1.⁠ ⁠Use the original government or statutory source wherever possible.
 2.⁠ ⁠Record the original URL for every document.
 3.⁠ ⁠Record the date on which each document was collected.
 4.⁠ ⁠Preserve publication or update dates when available.
 5.⁠ ⁠Do not rely on search-result snippets as source material.
 6.⁠ ⁠Do not use third-party summaries when an authoritative source is available.
 7.⁠ ⁠Store federal and state sources separately.
 8.⁠ ⁠Flag information that contains dates, payment rates, thresholds, or other values that may change.
 9.⁠ ⁠Re-check time-sensitive sources before including them in the production knowledge base.
10.⁠ ⁠Keep the source metadata attached to every document and chunk.
